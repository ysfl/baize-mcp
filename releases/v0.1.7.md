## 中文

0.1.7 将登录默认流程切换为浏览器授权：命令打开白泽授权页，你在页面中登录并确认授权，本机客户端自动完成后续流程，终端默认不再要求输入密码。

### 新增

- `baize-mcp login` 默认打开系统浏览器中的白泽授权页。登录并确认授权后，客户端获得会话凭据并存入操作系统凭据存储。
- 浏览器登录使用单次有效、短时过期的授权码和 PKCE S256 校验；回调只监听本机回环地址。
- 保留 `--password` 终端登录方式，适用于没有浏览器的环境（例如远程开发机）；该方式仍要求提供 `--username`，密码只在终端提示时输入。
- 已有且有效的会话可以继续使用；下次登录时使用浏览器流程。

### 兼容性

- 浏览器登录要求白泽 0.3.5 或更高版本，该版本提供 CLI 授权端点。
- 旧版本白泽服务端可以使用 `--password` 从终端登录。
- 本版本不改变工具及其权限。账号权限、审批、审计记录和任务状态仍由白泽服务端执行。

### 升级

- 用对应平台的压缩包替换现有可执行文件。profile 和已保存会话会保留。
- 最低兼容白泽版本提升到 0.3.5。
- 没有浏览器的机器请追加 `--password` 和 `--username`；密码只在终端提示时读取，不会出现在命令参数或配置文件中。

### 校验

- 下载后请核对 `SHA256SUMS` 中的 sha256 值与产物一致后再替换二进制。

## English

0.1.7 switches the default sign-in flow to browser authorization: the command opens the Baize authorization page, you sign in and approve there, and the local client completes the rest. The terminal no longer asks for a password by default.

### Added

- `baize-mcp login` opens the Baize authorization page in the system browser. After sign-in and approval, the client receives a session credential and stores it in the operating system credential storage.
- Browser sign-in uses a single-use, short-lived authorization code with PKCE S256 verification; the callback listens on a local loopback address only.
- `--password` keeps terminal sign-in for machines without a browser, such as a remote development host. This mode still requires `--username`, and the password is entered only at the terminal prompt.
- A valid saved session keeps working; browser sign-in applies the next time you sign in.

### Compatibility

- Browser sign-in requires Baize 0.3.5 or later, which provides the CLI authorization endpoints.
- On an older Baize server, use `--password` to sign in from the terminal.
- This release does not change the tools or their permissions. Account permissions, approvals, audit records and task state remain enforced by Baize.

### Upgrade

- Replace the existing executable with the archive for your platform. Profiles and saved sessions are kept.
- The minimum compatible Baize version is now 0.3.5.
- On a machine without a browser, pass `--password` and `--username`; the password is read from the terminal prompt and is never placed in command arguments or configuration files.

### Verification

- After downloading, verify the artifacts against `SHA256SUMS` before replacing the binary.
