## 中文

0.1.6 新增普通远程任务创建能力，与 0.3.2 服务端一起构成完整的一次性命令通道。

### 新增

- 新增 `baize_exec_task_create` 工具：一次性命令可直接创建普通远程任务，不需要模板、也不受直连白名单约束；权限、资源范围、命令安全引擎与审计由服务端统一生效。任务默认以待派发状态创建（`autoDispatch` 缺省关闭），可先审查再用 `baize_exec_task_dispatch` 派发。

### 兼容性

- 最低兼容白泽 0.2.2。
- 升级方式：替换本机 `baize-mcp` 可执行文件后重启 AI 客户端会话即可；会话凭据与 profile 无需重新登录。

### 校验

- 下载后请核对 `SHA256SUMS` 中的 sha256 值与产物一致后再替换二进制。

## English

0.1.6 adds regular remote task creation, completing the one-off command channel together with the 0.3.2 server.

### Added

- New `baize_exec_task_create` tool: one-off commands can now create a regular remote execution task directly — no template and no allowlist required; permissions, agent scope, the command safety engine and audit are enforced by the server. Tasks are created pending by default (`autoDispatch` off), so they can be reviewed and dispatched later with `baize_exec_task_dispatch`.

### Compatibility

- Minimum Baize version remains 0.2.2.
- Upgrade: replace the local `baize-mcp` binary and restart the AI client session; saved sessions and profiles stay valid.

### Verification

- After downloading, verify the artifacts against `SHA256SUMS` before replacing the binary.
